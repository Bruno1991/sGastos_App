## ✨ Principais Funcionalidades

- **100% Livre de Anúncios:** Todo o código de propaganda, AdMob, pedidos de avaliação e rastreadores foi completamente removido.
- **Privacidade & Offline-First:** Nenhum dado financeiro é enviado para servidores externos. Tudo fica armazenado localmente no `localStorage` do seu próprio navegador.
- **Gestão Completa de Gastos:**
  - Registro rápido de receitas e despesas por data e categoria.
  - Calendário interativo com indicadores diários de saldo.
  - Categorização com ícones e cores customizáveis.
- **Relatórios & Gráficos:** Visualização analítica da distribuição de gastos por período.
- **Multi-Moedas e Idiomas:** Suporte nativo a Real Brasileiro (R$ / BRL), Dólar ($ / USD), Euro (€ / EUR) e dezenas de outros idiomas e moedas.

## 💻 Como Rodar Localmente

Caso queira executar em seu próprio computador:

1. Clone o repositório:
   ```bash
   git clone https://github.com/Bruno1991/sGastos_App.git
   cd sGastos_App
   ```

2. Inicie qualquer servidor HTTP estático (por exemplo, com Python):
   ```bash
   python -m http.server 8080
   ```

3. Abra seu navegador em:
   ```
   http://localhost:8080
   ```
